# Device baseline

Known values from a retail OUKITEL RT7 TITAN 5G running its stock Android 13
firmware:

| Item | Value |
| --- | --- |
| Product/device | `P07_NFC_EEA` / `P07` |
| Board project | `tP758` |
| Kernel project | `tp758_oq_p07_nfc_6853_t0_eea` |
| SoC/platform | `MT6853V/ZA` / `mt6853` |
| CPU | 6x Cortex-A55 + 2x Cortex-A76 |
| GPU | Mali-G57 MC3 |
| Stock kernel | 4.19.191 |
| Storage | UFS, 256 GB class |
| RAM | 12 GB class |
| Battery | 32,000 mAh, 33 W charging |
| Boot layout | A/B, dynamic partitions, AVB |

Do not add serial numbers, MAC addresses, IMEI values, or unique partition data
to this document.
